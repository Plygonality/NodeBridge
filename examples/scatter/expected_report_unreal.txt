Approximations:
  Rock Shape (GeometryNodeMeshIcoSphere)
    Reason: The ico sphere becomes /Engine/BasicShapes/Sphere.Sphere scaled to size.
    - Mesh resolution and UVs differ.
  Coverage Noise (FunctionNodeCompare, ShaderNodeTexNoise, ShaderNodeMapRange)
    Reason: Consumed by the point filter that uses it.
    - PCG noise is 2D and differs numerically.
  Sink Rock (GeometryNodeTransform)
    Reason: Folded into the spawned mesh scale.
    - Translation and rotation of the instance geometry are dropped.
  Remove Sparse Areas (GeometryNodeDeleteGeometry)
    Reason: A noise-driven point deletion becomes PCG Spatial Noise written to density, filtered by the same threshold.
    - PCG's spatial noise is 2D and numerically different from Blender's noise.
  Place Rocks (GeometryNodeInstanceOnPoints, GeometryNodeRotateInstances)
    Reason: Instance on Points becomes a Static Mesh Spawner; mesh primitives map to /Engine/BasicShapes meshes scaled to size.
    - Geometry Nodes instances arbitrary geometry; PCG spawns Static Mesh assets.
    - Translation / rotation applied to the instance geometry is dropped; scale is kept.
  Realize Instances (GeometryNodeRealizeInstances)
    Reason: PCG spawns instanced static mesh components; there is no 'realize' step.
    - Spawned meshes stay instances.
  Rock Noise (ShaderNodeTexNoise)
    Reason: Blender fBm noise approximated with Unreal's gradient noise expression (output 0..1).
    - Pattern will not be numerically identical.
    - Color output reuses the scalar noise.
  Rock Bump (ShaderNodeBump)
    Reason: Height-based bump approximated from screen-space derivatives (no height-to-normal expression is constructible from Python).
    - Bump detail depends on screen resolution; strength is matched only roughly.

Equivalent (intent preserved, details differ):
  Geometry (NodeGroupInput)
    Reason: The actor or volume owning the PCG component replaces the modifier object.
    - Assign the graph to a PCG Volume or a PCG Component on the actor you want to populate.
  Scatter Rocks (GeometryNodeDistributePointsOnFaces)
    Reason: Distribute Points on Faces becomes a Surface Sampler with the same density per square meter.
    - Sample positions differ (different generators).
  Rock Material (GeometryNodeSetMaterial)
    Reason: Material assigned as the spawner's override material.
  Random Scale (FunctionNodeRandomValue, GeometryNodeInstanceOnPoints)
    Reason: Random rotation / scale ranges become Transform Points min/max ranges.
    - PCG's random stream differs from Blender's; ranges are preserved.
    - Euler ranges are mapped per axis to roll / pitch / yaw.
  Random Rotation (FunctionNodeRandomValue, GeometryNodeRotateInstances)
    Reason: Random rotation / scale ranges become Transform Points min/max ranges.
    - PCG's random stream differs from Blender's; ranges are preserved.
    - Euler ranges are mapped per axis to roll / pitch / yaw.
  Join Geometry (GeometryNodeJoinGeometry)
    Reason: Join Geometry becomes Merge Points.
    - Mesh geometry inputs are not merged; only point data and spawned results flow on.
  Geometry (NodeGroupOutput)
    Reason: Final point data / spawned meshes.
  Texture Coordinate Object (ShaderNodeTexCoord)
    Reason: Coordinates converted to Blender conventions (UV V flipped; positions in meters, right-handed).
    - Blender's Generated coordinates are bounding-box normalized; Unreal local position is not.
  Principled BSDF (ShaderNodeBsdfPrincipled)
    Reason: Principled BSDF inputs map onto Unreal's Default Lit shading model; both are PBR but not identical.
    - Coat, sheen, subsurface and transmission are not mapped.
    - Alpha below 1 needs a translucent / masked blend mode.
