Approximations:
  Coverage Noise (FunctionNodeCompare, ShaderNodeTexNoise, ShaderNodeMapRange)
    Reason: Noise of position compared with a threshold; Houdini's noise differs numerically from Blender's.
    - Mask boundaries follow the same parameters but not the same pattern.
  [ProceduralRock] Rock Noise (ShaderNodeTexNoise)
    Reason: Blender fBm noise approximated with MaterialX fractal noise remapped to 0..1.
    - Pattern will not be numerically identical.
    - Color output reuses the scalar noise.

Equivalent (intent preserved, details differ):
  Geometry (NodeGroupInput)
    Reason: The modifier's input geometry becomes an Object Merge you point at your own object. Until then a placeholder sized like the Blender object is used.
    - Set 'Use Source Object' on the geo node and the Object Merge path to use real geometry.
  Rock Shape (GeometryNodeMeshIcoSphere)
    Reason: Native ico sphere primitive; vertex layout and UVs differ.
    - Topology (vertex order, pole layout, UVs) differs from Blender.
  Scatter Rocks (GeometryNodeDistributePointsOnFaces)
    Reason: Distribute Points on Faces becomes a Scatter SOP driven by density per square unit.
    - Random sample positions differ from Blender (different random generators).
  Rock Material (GeometryNodeSetMaterial)
    Reason: Set Material becomes a Material SOP pointing at /mat/<name>.
    - The material network is generated only when the Blender material uses nodes.
  Random Scale (FunctionNodeRandomValue, GeometryNodeInstanceOnPoints)
    Reason: Per-point random rotation and scale ranges written as instancing attributes with NodeBridge's deterministic random.
    - Random values differ from Blender's sequence; ranges and distribution are preserved.
  Random Rotation (FunctionNodeRandomValue, GeometryNodeRotateInstances)
    Reason: Per-point random rotation and scale ranges written as instancing attributes with NodeBridge's deterministic random.
    - Random values differ from Blender's sequence; ranges and distribution are preserved.
  [ProceduralRock] Texture Coordinate Object (ShaderNodeTexCoord)
    Reason: Texture coordinates map onto MaterialX geometric inputs.
    - Blender's Generated coordinates are bounding-box normalized; MaterialX object position is not.
    - Axes follow Houdini's Y-up convention.
  [ProceduralRock] Rock Bump (ShaderNodeBump)
    Reason: Height-driven normal perturbation.
    - Bump distance is folded into the scale.
  [ProceduralRock] Principled BSDF (ShaderNodeBsdfPrincipled)
    Reason: Principled BSDF maps onto Autodesk Standard Surface; both are physically based but not identical models.
    - Specular IOR Level is mapped to specular weight (x2).
    - Alpha is mapped to opacity.
